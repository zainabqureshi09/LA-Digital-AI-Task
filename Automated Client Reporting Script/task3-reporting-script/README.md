# Automated Client Reporting System

A Python-based tool for digital marketing agencies to automatically generate professional PDF performance reports from CSV campaign data.

## 🚀 Features
- **Automatic KPI Calculations**: Computes CTR (Click-Through Rate) and Cost Per Lead (CPL) automatically.
- **Visual Analytics**: Generates performance trend charts using Matplotlib.
- **Professional PDF Export**: Creates a clean, client-ready PDF report with summaries and detailed tables.
- **Data-Driven**: Easily updateable by modifying the source CSV.

## 📂 Project Structure
- `report.py`: The main Python script that handles data processing and PDF generation.
- `data.csv`: Input file containing your campaign data (Date, Spend, Impressions, Clicks, Leads).
- `requirements.txt`: List of required Python libraries.
- `chart.png`: Generated chart image (auto-generated by the script).
- `report.pdf`: The final professional report (auto-generated by the script).

## 🛠️ Setup Instructions

### 1. Install Python
Ensure you have Python 3.x installed on your system.

### 2. Install Dependencies
Open your terminal or command prompt in this directory and run:
```bash
pip install -r requirements.txt
```

### 3. Prepare Your Data
Open `data.csv` and add your campaign data following this format:
`Date, Spend, Impressions, Clicks, Leads`

### 4. Run the Script
Execute the following command to generate your report:
```bash
python report.py
```

## 📊 How it Works
1. **Data Loading**: The script uses `pandas` to read and clean the CSV file.
2. **Calculations**: It applies marketing formulas to derive performance metrics.
3. **Visualization**: `matplotlib` creates a visual representation of the data trends.
4. **PDF Compilation**: `reportlab` builds the final document, combining text, tables, and images into a professional layout.
