# LA Digital Agency - AI Add-on Proposal

This project contains a professional AI Add-on Proposal for **LA Digital Agency**, focusing on an AI Chatbot for Lead Generation.

## Navigation

All project files, including the generated presentation and source scripts, are located in the [task4-ai-proposal/](./task4-ai-proposal/) directory.

### Quick Start
To view the proposal and its supporting assets:
1. Navigate to `task4-ai-proposal/`
2. Open `proposal.pptx`
3. View mockups in `screenshots/`

For detailed setup and regeneration instructions, see [task4-ai-proposal/README.md](./task4-ai-proposal/README.md).
