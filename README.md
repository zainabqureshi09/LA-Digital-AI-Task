# LA-Digital-AI-Task

AI Solutions Consultant Task Submission for LA Digital Agency.

## Overview

This repository contains solutions for the AI Solutions Task Brief provided by LA Digital Agency.

The project includes:

1. Marketing Agency Lead Scraping Automation
2. RAG AI Chatbot for Real Estate Client
3. Automated Client Reporting System
4. AI Add-on Proposal for Marketing Clients



# Task 1 — Lead Scraping Automation

Python automation script that scrapes business lead data from Google Maps and exports structured CSV data.

### Features

* Google Maps scraping
* CSV export
* Business lead collection
* Automation workflow

### Technologies Used

* Python
* Selenium
* Pandas
* webdriver-manager
